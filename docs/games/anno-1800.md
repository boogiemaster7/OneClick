# Anno 1800: tuning plan

Steam app 916440 · Game Update 18.4 (Dec 2024, final content update) · Ubisoft Mainz in-house engine ·
Direct3D 11 / 12 · Denuvo + VMProtect + Ubisoft Connect · no anti-cheat.

Goal: a **steady 60 fps, including large late-game cities**, on an M5 Pro MacBook Pro 16" through D3DMetal
(GPTK 4.0 beta 2). Tags: **[Official]** Ubisoft/Steam · **[Measured]** a benchmark or user measured it ·
**[Claim]** community report · **[Ours]** to be measured here.

## The launch chain
Steam starts `Bin\Win64\Anno1800.exe -uplay_steam_mode` [Official, Steam launch config]. The game brings
up **Ubisoft Connect** in the same prefix, which checks ownership and then lets the game run. OneClick
starts the exe directly, so its profile passes `-uplay_steam_mode` itself.

Ubisoft Connect's window is an embedded Chromium browser. On plain Wine it never paints (white or black)
because its GPU process can't present into the browser process's window: Wine bug 60263. OneClick's
Wine build carries the fix (`Scripts/patches/wine/0003-winemac-cross-process-child-swapchains.patch`).
Highball verified Connect on DXMT with `DXMT_ALLOW_CROSS_PROCESS_SWAPCHAIN=1` (an opt-in that only exists
in its DXMT fork); D3DMetal with the Wine fix alone is untested. **Try D3DMetal first**, since that would
need no per-process renderer split.

**Denuvo:** activating on "different machines or settings" can lock the game ("Product cannot be
activated right now") for a day or two [Claim, CodeWeavers staff]. Launch Anno for the first time on the
final Wine build, and avoid switching runtimes or prefixes often.

## Engine facts
- Direct3D 11 and 12, no Vulkan. Select DX12 in the game's options or in `engine.ini`:
  `"RenderEngine": { "DeviceType": "DX12" }` [Official, Ubisoft support post].
- In CPU-limited late game, DX12 measured 31–50 % faster than DX11 on Windows (32.1 vs 22.0 fps); DX11
  has smoother frame times [Measured, PCGH].
- On the Mac, D3DMetal + DX12 is the consensus; DX11 on DXVK shows glitches; nobody reports DXMT
  [Claim, CodeWeavers forum].
- **No in-game frame limiter** [Official, Ubisoft staff]; **FSR 1 is the only upscaler**, four modes
  [Official, Game Update 11.1].
- Config: `%USERPROFILE%\Documents\Anno 1800\config\engine.ini` (JSON). In the bottle:
  `drive_c/users/crossover/Documents/Anno 1800/config/engine.ini`. Mods: built-in mod loader since Game
  Update 17; drop mods into `Documents\Anno 1800\mods` (the in-game mod.io browser is broken under
  CrossOver [Claim]).

## The levers, in test order

| # | Lever | How | Source | Expected |
|---|---|---|---|---|
| 1 | API | `DeviceType: DX12` | [Official] key · [Measured] 31–50 % in late game | Large (CPU-bound) |
| 2 | Render resolution | `ScreenXSize 1728`, `ScreenYSize 1117`, Wine RetinaMode off | Manor Lords / GameToMac approach | Large (GPU) |
| 3 | Preset | High instead of Very High: +43 % in a CPU-limited test; Ultra adds 8× MSAA | [Measured, PCGH] | Large |
| 4 | City CPU load | Lower **Object**, **View distance**, **Shadow**, **Crowd density** (`FeedbackQualityLevel`) | [Measured, PCGH] · one player 20–25 → 30–40 fps from crowd alone [Claim] | Large late game |
| 5 | Frame cap | `D3DM_MAX_FPS=60` (no in-game limiter), VSYNC 0 | [Official] no limiter · GPTK Read Me | Even pacing |
| 6 | Raytracing off | `D3DM_SUPPORT_DXR=0` | GPTK Read Me; the game has none | Free |
| 7 | Anti-aliasing | 0–1 (no MSAA) | [Measured] MSAA is Ultra's main cost | Medium |
| 8 | Upscaling | FSR 1 Ultra Quality only if GPU-bound at 1728×1117 | [Measured, PCGH] | Situational |
| 9 | Textures | High (unified memory makes them nearly free) | Manor Lords lesson | Keeps it sharp |
| 10 | Display | 60 Hz fixed vs ProMotion | M5 Pro + macOS 27 pacing report | Smoothness |
| 11 | Long sessions | Restart every ~2 h; fps decays the longer a scene stays loaded | [Measured, PCGH] · [Claim] Mac crashes after 2–3 h | Stability |

Do **not** use: the retired community mod loader (`python35.dll` proxy); the Ubisoft Connect in-game
overlay (turn it off in Connect's settings).
